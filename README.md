## Sobre

Engenheiro de software em formação, focado em construir sistemas **performáticos, seguros e bem arquitetados**. Trabalho com desenvolvimento full-stack, desde a modelagem de dados até interfaces cinematográficas — sem entregar código genérico.

Atualmente desenvolvendo **Izanagi AI**, um framework de engenharia de software autônoma orientada a agentes (CLI publicada no npm), com arquitetura em camadas: Decision → Context → Skill → Quality → Reflection → Memory.
